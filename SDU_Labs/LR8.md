## 2. Краткий экскурс в Verilog для арифметических операций

В Verilog арифметические операции (`+`, `-`, `*`, `/`, `%`) поддерживаются на уровне языка, но для учебных целей полезно реализовать сумматоры структурно (из вентилей) или комбинировать поведенческий и структурный подходы.

### 2.1. Базовые операторы

```verilog
assign sum = a + b;       // сложение
assign diff = a - b;      // вычитание
assign prod = a * b;      // умножение
assign lt = (a < b);      // сравнение
```

### 2.2. Векторы (шины данных)

```verilog
input  [3:0] a, b;        // 4-битные числа
output [4:0] sum;         // 5 бит для учёта переноса
```

### 2.3. Структурное описание полного сумматора

```verilog
module full_adder (
    input  a, b, cin,
    output sum, cout
);
    assign sum  = a ^ b ^ cin;
    assign cout = (a & b) | (a & cin) | (b & cin);
endmodule
```

### 2.4. Установка инструментов

## 3. Теоретическая часть

**Сумматор** – устройство для арифметического сложения двоичных кодов.

### 3.1. Одноразрядные сумматоры

| Тип | Входы | Выходы | Описание |
|-----|-------|--------|----------|
| **Четвертьсумматор** (XOR) | A, B | S = A⊕B | сумма без учёта переноса |
| **Полусумматор** (HA) | A, B | S, Cout = A&B | сумма и перенос |
| **Полный сумматор** (FA) | A, B, Cin | S, Cout | сумма с учётом входящего переноса |

### 3.2. Многоразрядные сумматоры

- **Параллельный сумматор** – цепочка полных сумматоров, перенос распространяется последовательно (ripple carry).
- **Сумматор с ускоренным переносом** – для повышения быстродействия (не рассматривается).

### 3.3. Вычитание с помощью сумматора

Вычитание `A - B` можно заменить сложением: `A + (~B) + 1` (дополнительный код).  
Для обратного кода: `A + (~B)` (без добавления 1). При этом для получения правильного результата в обратном коде нужна коррекция (циклический перенос). На практике чаще используют дополнительный код.

**Обнаружение переполнения** для знаковых чисел (дополнительный код):
- Переполнение возникает, если знаки операндов одинаковы, а знак результата отличается.
- В схеме: `overflow = (a[n-1] == b[n-1]) && (sum[n-1] != a[n-1])`.

### 3.4. Компаратор

Сравнивает два двоичных числа и выдаёт сигналы `A_gt_B`, `A_lt_B`, `A_eq_B`.

### 3.5. Умножитель

Умножение двоичных чисел можно реализовать как последовательное сложение (сдвиг и сумма). Для простоты в данной работе используется поведенческое описание `*`.

## 4. Verilog-модели и тестовые стенды

### 4.1. Полный сумматор (структурный)

**Модуль `full_adder.v`:**

```verilog
module full_adder (
    input  wire a, b, cin,
    output wire sum, cout
);
    assign sum  = a ^ b ^ cin;
    assign cout = (a & b) | (a & cin) | (b & cin);
endmodule
```

### 4.2. 4-разрядный параллельный сумматор (структурный)

**Модуль `ripple_adder_4bit.v`:**

```verilog
module ripple_adder_4bit (
    input  [3:0] a, b,
    input  cin,
    output [3:0] sum,
    output cout
);
    wire c1, c2, c3;
    full_adder fa0 (a[0], b[0], cin,  sum[0], c1);
    full_adder fa1 (a[1], b[1], c1,   sum[1], c2);
    full_adder fa2 (a[2], b[2], c2,   sum[2], c3);
    full_adder fa3 (a[3], b[3], c3,   sum[3], cout);
endmodule
```

### 4.3. 4-разрядный сумматор (поведенческий)

```verilog
module adder_4bit_beh (
    input  [3:0] a, b,
    input  cin,
    output [4:0] result   // включая перенос
);
    assign result = a + b + cin;
endmodule
```

### 4.4. Вычитатель в дополнительном коде (A - B)

**Модуль `subtractor_2s_complement.v`:**

```verilog
module subtractor_2s_complement #(parameter WIDTH = 4) (
    input  [WIDTH-1:0] a, b,
    output [WIDTH-1:0] diff,
    output overflow
);
    wire [WIDTH-1:0] not_b = ~b;
    wire [WIDTH:0] sum = a + not_b + 1;
    assign diff = sum[WIDTH-1:0];
    // Обнаружение переполнения для знаковых чисел
    assign overflow = (a[WIDTH-1] == ~b[WIDTH-1]) && (diff[WIDTH-1] != a[WIDTH-1]);
endmodule
```

**Testbench:**

```verilog
`timescale 1ns / 1ps
module subtractor_tb();
    reg [3:0] a, b;
    wire [3:0] diff;
    wire overflow;
    
    subtractor_2s_complement #(.WIDTH(4)) dut (a, b, diff, overflow);
    
    initial begin
        $dumpfile("subtractor.vcd");
        $dumpvars(0, subtractor_tb);
        a = 4'b0101; b = 4'b0011; #10; // 5-3=2
        a = 4'b0011; b = 4'b0101; #10; // 3-5=-2 (1110)
        a = 4'b0111; b = 4'b1000; #10; // 7-(-8)=15? переполнение
        a = 4'b1000; b = 4'b0111; #10; // -8-7=-15 переполнение
        $finish;
    end
endmodule
```

### 4.5. Вычитатель в обратном коде (A - B)

```verilog
module subtractor_1s_complement #(parameter WIDTH = 4) (
    input  [WIDTH-1:0] a, b,
    output [WIDTH-1:0] diff,
    output end_carry
);
    wire [WIDTH-1:0] not_b = ~b;
    wire [WIDTH:0] sum = a + not_b;
    assign diff = sum[WIDTH-1:0];
    assign end_carry = sum[WIDTH];
endmodule
```
*Примечание:* в обратном коде требуется циклический перенос (end_carry добавляется к результату), здесь опущено для простоты.

### 4.6. Компаратор

```verilog
module comparator #(parameter WIDTH = 4) (
    input  [WIDTH-1:0] a, b,
    output reg gt, lt, eq
);
    always @(*) begin
        gt = (a > b);
        lt = (a < b);
        eq = (a == b);
    end
endmodule
```

### 4.7. Умножитель (поведенческий)

```verilog
module multiplier #(parameter WIDTH = 4) (
    input  [WIDTH-1:0] a, b,
    output [2*WIDTH-1:0] prod
);
    assign prod = a * b;
endmodule
```

### 4.8. Сумматор в дополнительном коде с обнаружением переполнения

```verilog
module adder_2s_complement #(parameter WIDTH = 4) (
    input  [WIDTH-1:0] a, b,
    output [WIDTH-1:0] sum,
    output overflow
);
    wire [WIDTH:0] result = a + b;
    assign sum = result[WIDTH-1:0];
    assign overflow = (a[WIDTH-1] == b[WIDTH-1]) && (sum[WIDTH-1] != a[WIDTH-1]);
endmodule
```
