## 2. Краткое напоминание по Verilog для последовательностных схем

Подробное введение в Verilog приведено в `Лабораторной работе №3` и `Лабораторной работе №4`. Напомним ключевые моменты для описания триггеров:

- **Тактовый сигнал** – сигнал синхронизации, обычно `clk`. Изменение состояния происходит по переднему фронту (`posedge clk`) или по заднему (`negedge clk`).
- **Асинхронный сброс** – сигнал `rst`, который немедленно устанавливает триггер в `0` независимо от такта. Добавляется в список чувствительности: `always @(posedge clk or posedge rst)`.
- **Неблокирующие присваивания (`<=`)** – используются в блоках `always @(posedge clk ...)` для корректного моделирования работы триггеров.

**Пример D-триггера с асинхронным сбросом:**

```verilog
module d_ff (
    input wire clk, rst,
    input wire d,
    output reg q,
    output wire qn
);
    assign qn = ~q;
    always @(posedge clk or posedge rst) begin
        if (rst)
            q <= 1'b0;
        else
            q <= d;
    end
endmodule
```

## 4. Теоретическая часть

### 4.1. D-триггер (Delay / Data)

D-триггер имеет один информационный вход `D` и тактовый вход `C` (или `clk`). По фронту тактового сигнала значение на входе `D` передаётся на выход `Q`. Это простейший элемент памяти, используемый в регистрах и сдвиговых регистрах.

#### Таблица переходов D-триггера (по переднему фронту `C`)

| C   | D | Q(t+1) |
|-----|---|--------|
| ↑   | 0 | 0      |
| ↑   | 1 | 1      |
| 0,1 | x | Q(t)   |

#### Характеристическое уравнение

`Q(t+1) = D`

### 4.2. JK-триггер (универсальный)

JK-триггер имеет два синхронных входа `J` и `K`. Он подобен RS-триггеру, но комбинация `J=1, K=1` не является запрещённой, а вызывает инверсию состояния (режим T-триггера). Благодаря этому JK-триггер может выполнять функции RS-, D- и T-триггера, что делает его универсальным.

#### Таблица переходов JK-триггера (по переднему фронту `C`)

| J | K | Q(t) | Q(t+1) | Режим          |
|---|---|------|--------|----------------|
| 0 | 0 | 0    | 0      | Хранение       |
| 0 | 0 | 1    | 1      | Хранение       |
| 0 | 1 | 0    | 0      | Сброс (Reset)  |
| 0 | 1 | 1    | 0      | Сброс          |
| 1 | 0 | 0    | 1      | Установка (Set)|
| 1 | 0 | 1    | 1      | Установка      |
| 1 | 1 | 0    | 1      | Инверсия (Toggle) |
| 1 | 1 | 1    | 0      | Инверсия       |

#### Характеристическое уравнение

`Q(t+1) = J · Q' + K' · Q`  (при `C=1`)

#### Универсальность JK-триггера

| Желаемый тип | Подключение входов               |
|--------------|----------------------------------|
| RS-триггер   | J = S, K = R                     |
| D-триггер    | J = D, K = D'                    |
| T-триггер    | J = 1, K = 1 (или объединены)    |

### 4.3. Счётчик Джонсона (кольцевой счётчик с инверсией)

Счётчик Джонсона (или сдвиговый регистр с инверсной обратной связью) строится на основе D-триггеров (или JK, работающих в режиме T). Выход последнего триггера инвертируется и подаётся на вход первого. Такая схема позволяет получить последовательность состояний, в которой каждый такт сдвигается единица, затем – нули.

#### Пример для 4-разрядного счётчика Джонсона

Состояния (Q3 Q2 Q1 Q0) при начальном сбросе `0000`:

1. `0000`
2. `1000`
3. `1100`
4. `1110`
5. `1111`
6. `0111`
7. `0011`
8. `0001`
9. `0000` (повтор)

Количество различных состояний: `2n`, где `n` – число триггеров. Для 4 триггеров – 8 состояний.

Схема: выход `Q3` (последнего) инвертируется и подаётся на вход `D0` первого триггера.

## 5. Verilog-модели и тестовые стенды

### 5.1. D-триггер с асинхронным сбросом

**Модуль `d_ff.v`:**

```verilog
module d_ff (
    input wire clk,
    input wire rst,
    input wire d,
    output reg q,
    output wire qn
);
    assign qn = ~q;
    
    always @(posedge clk or posedge rst) begin
        if (rst)
            q <= 1'b0;
        else
            q <= d;
    end
endmodule
```

**Testbench `d_ff_tb.v`:**

```verilog
`timescale 1ns / 1ps
module d_ff_tb();
    reg clk, rst, d;
    wire q, qn;
    
    d_ff dut (clk, rst, d, q, qn);
    
    always #5 clk = ~clk;
    
    initial begin
        $dumpfile("d_ff.vcd");
        $dumpvars(0, d_ff_tb);
        clk = 0; rst = 1; d = 0;
        #12 rst = 0;        // снятие сброса
        #10 d = 1;
        #10 d = 0;
        #10 d = 1;
        #10 d = 1;
        #10 d = 0;
        #20 $finish;
    end
endmodule
```

**Запуск:**
```bash
iverilog -o d_ff_tb.vvp d_ff_tb.v d_ff.v
vvp d_ff_tb.vvp
gtkwave d_ff.vcd
```

### 5.2. JK-триггер (поведенческая модель)

**Модуль `jk_ff.v`:**

```verilog
module jk_ff (
    input wire clk,
    input wire rst,
    input wire j, k,
    output reg q,
    output wire qn
);
    assign qn = ~q;
    
    always @(posedge clk or posedge rst) begin
        if (rst)
            q <= 1'b0;
        else begin
            case ({j, k})
                2'b00: q <= q;
                2'b01: q <= 1'b0;
                2'b10: q <= 1'b1;
                2'b11: q <= ~q;
            endcase
        end
    end
endmodule
```

**Testbench `jk_ff_tb.v`:**

```verilog
`timescale 1ns / 1ps
module jk_ff_tb();
    reg clk, rst, j, k;
    wire q, qn;
    
    jk_ff dut (clk, rst, j, k, q, qn);
    
    always #5 clk = ~clk;
    
    initial begin
        $dumpfile("jk_ff.vcd");
        $dumpvars(0, jk_ff_tb);
        clk = 0; rst = 1; j = 0; k = 0;
        
        #12 rst = 0;
        // режим хранения
        #10 j=0; k=0;
        #10 j=0; k=1;  // сброс
        #10 j=1; k=0;  // установка
        #10 j=1; k=1;  // инверсия
        #10 j=1; k=1;  // ещё одна инверсия
        #20 $finish;
    end
endmodule
```

### 5.3. Счётчик Джонсона на D-триггерах (4-разрядный)

**Модуль `johnson_counter.v`:**

```verilog
module johnson_counter (
    input wire clk,
    input wire rst,
    output wire [3:0] q
);
    wire q0, q1, q2, q3;
    wire q3_inv;
    
    assign q = {q3, q2, q1, q0};
    assign q3_inv = ~q3;
    
    d_ff ff0 (clk, rst, q3_inv, q0);
    d_ff ff1 (clk, rst, q0,    q1);
    d_ff ff2 (clk, rst, q1,    q2);
    d_ff ff3 (clk, rst, q2,    q3);
endmodule
```

**Тестовый стенд `johnson_tb.v`:**

```verilog
`timescale 1ns / 1ps
module johnson_tb();
    reg clk, rst;
    wire [3:0] q;
    
    johnson_counter dut (clk, rst, q);
    
    always #5 clk = ~clk;
    
    initial begin
        $dumpfile("johnson.vcd");
        $dumpvars(0, johnson_tb);
        clk = 0; rst = 1;
        #15 rst = 0;
        #160 $finish;  // 16 тактов – два полных цикла
    end
endmodule
```

**Запуск:**
```bash
iverilog -o johnson_tb.vvp johnson_tb.v johnson_counter.v d_ff.v
vvp johnson_tb.vvp
gtkwave johnson.vcd
```

*Примечание:* на диаграмме `gtkwave` можно увидеть последовательность `0000` → `1000` → `1100` → `1110` → `1111` → `0111` → `0011` → `0001` → `0000`.
