### 2.2. Основы языка Verilog, необходимые для работы

Verilog позволяет описывать цифровые устройства на разных уровнях абстракции. В данной работе мы будем использовать **поведенческое** и **потоковое** описание комбинационных схем.

#### Модуль и порты

Любое устройство описывается модулем:

```verilog
module my_device (
    input  wire a, b,      // входы
    output wire y          // выход
);
    // внутренняя логика
endmodule
```

#### Непрерывное присваивание (потоковое описание)

Используется для простых комбинационных выражений:

```verilog
assign y = a & b;   // логическое И
assign y = a | b;   // ИЛИ
assign y = ~a;      // НЕ
```

#### Блок `always @*` (поведенческое описание)

Используется для описания более сложной комбинационной логики, например, мультиплексоров:

```verilog
always @(*) begin
    case (sel)
        2'b00: y = x0;
        2'b01: y = x1;
        2'b10: y = x2;
        2'b11: y = x3;
    endcase
end
```

#### Регистровые переменные (`reg`) и блоки `always @(posedge clk)`

Для описания последовательностных устройств (триггеров, регистров, счётчиков) используются **неблокирующие присваивания `<=`**:

```verilog
always @(posedge clk) begin
    if (rst)
        count <= 0;
    else
        count <= count + 1;
end
```

> **Примечание:** в данной лабораторной работе все устройства – комбинационные, поэтому мы не будем использовать тактовые сигналы. Однако знание `always @*` и `case` нам пригодится.

#### Структурное описание (подключение подсхем)

Модули могут быть вложенными:

```verilog
decoder_2x4 dec_inst (
    .a(a), .b(b), .en(en),
    .y0(y0), .y1(y1), .y2(y2), .y3(y3)
);
```

#### Тестовый стенд (testbench)

Testbench – это модуль, который не имеет портов, генерирует входные воздействия и выводит результаты симуляции:

```verilog
`timescale 1ns / 1ps
module my_tb();
    reg a, b;
    wire y;
    
    my_device dut (a, b, y);
    
    initial begin
        $dumpfile("waveform.vcd");
        $dumpvars(0, my_tb);
        
        a = 0; b = 0; #10;
        a = 0; b = 1; #10;
        a = 1; b = 0; #10;
        a = 1; b = 1; #10;
        
        $finish;
    end
endmodule
```

Запуск симуляции:

```bash
iverilog -o my_tb.vvp my_tb.v my_device.v
vvp my_tb.vvp
gtkwave waveform.vcd
```

## 3. Объекты исследования и их Verilog-модели

### 3.1. Дешифраторы

**Дешифратор** преобразует двоичный код на входе в сигнал «1» на одном из выходов (унарный код). Полный дешифратор с `n` входами имеет `2^n` выходов.

#### Линейный дешифратор 2×4

Схема, реализованная на элементах «И», описывается следующими логическими выражениями:

```
Y0 = ~A1 & ~A0
Y1 = ~A1 &  A0
Y2 =  A1 & ~A0
Y3 =  A1 &  A0
```

**Verilog-модуль (потоковое описание):**

```verilog
module decoder_2x4 (
    input  wire a1, a0,
    input  wire en,          // вход разрешения (активный высокий уровень)
    output wire y0, y1, y2, y3
);
    assign y0 = en & ~a1 & ~a0;
    assign y1 = en & ~a1 &  a0;
    assign y2 = en &  a1 & ~a0;
    assign y3 = en &  a1 &  a0;
endmodule
```

**Testbench для дешифратора 2×4:**

```verilog
`timescale 1ns / 1ps
module decoder_tb();
    reg a1, a0, en;
    wire y0, y1, y2, y3;
    
    decoder_2x4 dut (a1, a0, en, y0, y1, y2, y3);
    
    initial begin
        $dumpfile("decoder.vcd");
        $dumpvars(0, decoder_tb);
        
        // перебор всех комбинаций входов
        en = 1;
        {a1, a0} = 2'b00; #10;
        {a1, a0} = 2'b01; #10;
        {a1, a0} = 2'b10; #10;
        {a1, a0} = 2'b11; #10;
        
        en = 0;           // проверка запрета
        {a1, a0} = 2'b00; #10;
        
        $finish;
    end
endmodule
```

#### Каскадный дешифратор 4×16 из дешифраторов 2×4

Для увеличения числа входов можно использовать дешифраторы с входом разрешения. Например, для построения дешифратора 4×16 потребуется 5 дешифраторов 2×4 (один на старшие разряды и четыре на младшие).

**Структурное описание (фрагмент):**

```verilog
module decoder_4x16 (
    input  wire a3, a2, a1, a0,
    output wire [15:0] y
);
    wire en0, en1, en2, en3;
    // дешифратор старших разрядов (a3,a2)
    decoder_2x4 high (
        .a1(a3), .a0(a2), .en(1'b1),
        .y0(en0), .y1(en1), .y2(en2), .y3(en3)
    );
    // четыре дешифратора для младших разрядов
    decoder_2x4 low0 ( .a1(a1), .a0(a0), .en(en0), .y0(y[0]), .y1(y[1]), .y2(y[2]), .y3(y[3]) );
    decoder_2x4 low1 ( .a1(a1), .a0(a0), .en(en1), .y0(y[4]), .y1(y[5]), .y2(y[6]), .y3(y[7]) );
    decoder_2x4 low2 ( .a1(a1), .a0(a0), .en(en2), .y0(y[8]), .y1(y[9]), .y2(y[10]), .y3(y[11]) );
    decoder_2x4 low3 ( .a1(a1), .a0(a0), .en(en3), .y0(y[12]), .y1(y[13]), .y2(y[14]), .y3(y[15]) );
endmodule
```

#### Матричный дешифратор 4×16

Матричный дешифратор использует дешифраторы 2×4, выходы которых образуют сетку «горизонталь-вертикаль», а в узлах установлены элементы «И».

**Verilog-описание (структурное):**

```verilog
module matrix_decoder_4x16 (
    input  wire a3, a2, a1, a0,
    output wire [15:0] y
);
    wire [3:0] row, col;
    // дешифратор строк (старшие разряды)
    decoder_2x4 row_dec ( .a1(a3), .a0(a2), .en(1'b1), .y0(row[0]), .y1(row[1]), .y2(row[2]), .y3(row[3]) );
    // дешифратор столбцов (младшие разряды)
    decoder_2x4 col_dec ( .a1(a1), .a0(a0), .en(1'b1), .y0(col[0]), .y1(col[1]), .y2(col[2]), .y3(col[3]) );
    // матрица элементов "И"
    assign y[0]  = row[0] & col[0];
    assign y[1]  = row[0] & col[1];
    assign y[2]  = row[0] & col[2];
    assign y[3]  = row[0] & col[3];
    assign y[4]  = row[1] & col[0];
    // ... и так далее для всех 16 выходов
    assign y[15] = row[3] & col[3];
endmodule
```

### 3.2. Шифраторы

**Шифратор** преобразует унарный код (активный вход) в двоичный код на выходе. Пример – шифратор 10×4 (преобразование десятичных цифр 0…9 в двоичный код).

#### Логические выражения

Из таблицы истинности (см. оригинальную методичку) получаем:

```
Y0 = K1 + K3 + K5 + K7 + K9
Y1 = K2 + K3 + K6 + K7
Y2 = K4 + K5 + K6 + K7
Y3 = K8 + K9
```

**Реализация на элементах «ИЛИ» (потоковое описание):**

```verilog
module encoder_10x4_or (
    input  wire k0, k1, k2, k3, k4, k5, k6, k7, k8, k9,
    output wire y0, y1, y2, y3
);
    assign y0 = k1 | k3 | k5 | k7 | k9;
    assign y1 = k2 | k3 | k6 | k7;
    assign y2 = k4 | k5 | k6 | k7;
    assign y3 = k8 | k9;
endmodule
```

**Реализация на элементах «И-НЕ» (базис Шеффера):**

Используя теорему де Моргана: `A + B = ~(~A & ~B)`. Следовательно, шифратор на «И-НЕ» можно получить, дополнив каждый выход инвертором. Однако проще описать логику через `assign` с использованием `~&` (И-НЕ):

```verilog
module encoder_10x4_nand (
    input  wire k0, k1, k2, k3, k4, k5, k6, k7, k8, k9,
    output wire y0, y1, y2, y3
);
    // внутренние инвертированные сигналы
    wire ny0, ny1, ny2, ny3;
    assign ny0 = ~(k1 & k3 & k5 & k7 & k9);   // И-НЕ
    assign ny1 = ~(k2 & k3 & k6 & k7);
    assign ny2 = ~(k4 & k5 & k6 & k7);
    assign ny3 = ~(k8 & k9);
    // дополнительный инвертор на выходе (чтобы получить исходную функцию)
    assign y0 = ~ny0;
    assign y1 = ~ny1;
    assign y2 = ~ny2;
    assign y3 = ~ny3;
endmodule
```

**Testbench для шифратора:**

```verilog
`timescale 1ns / 1ps
module encoder_tb();
    reg k0,k1,k2,k3,k4,k5,k6,k7,k8,k9;
    wire y0,y1,y2,y3;
    
    encoder_10x4_or dut (k0,k1,k2,k3,k4,k5,k6,k7,k8,k9, y0,y1,y2,y3);
    
    initial begin
        $dumpfile("encoder.vcd");
        $dumpvars(0, encoder_tb);
        
        // активируем по одному входу
        {k9,k8,k7,k6,k5,k4,k3,k2,k1,k0} = 10'b0000000001; #10; // 0 -> 0000
        {k9,k8,k7,k6,k5,k4,k3,k2,k1,k0} = 10'b0000000010; #10; // 1 -> 0001
        {k9,k8,k7,k6,k5,k4,k3,k2,k1,k0} = 10'b0000000100; #10; // 2 -> 0010
        // ... и так до 9
        $finish;
    end
endmodule
```

### 3.3. Мультиплексоры

**Мультиплексор** подключает один из информационных входов к выходу согласно адресному коду. Для 4-канального мультиплексора (2 адресных входа) логическое выражение:

```
Y = E & ( ~A1 & ~A0 & X0
        | ~A1 &  A0 & X1
        |  A1 & ~A0 & X2
        |  A1 &  A0 & X3 )
```

**Реализация на элементах «И» и «ИЛИ» (структурная):**

```verilog
module mux_4x1_and_or (
    input  wire e, a1, a0,
    input  wire x0, x1, x2, x3,
    output wire y
);
    wire w0, w1, w2, w3;
    assign w0 = e & ~a1 & ~a0 & x0;
    assign w1 = e & ~a1 &  a0 & x1;
    assign w2 = e &  a1 & ~a0 & x2;
    assign w3 = e &  a1 &  a0 & x3;
    assign y  = w0 | w1 | w2 | w3;
endmodule
```

**Реализация на элементах «И-НЕ» (преобразование по Шеннону):**

Используем тождество: `Y = ~( ~(w0) & ~(w1) & ~(w2) & ~(w3) )`. Тогда:

```verilog
module mux_4x1_nand (
    input  wire e, a1, a0,
    input  wire x0, x1, x2, x3,
    output wire y
);
    wire w0, w1, w2, w3;
    assign w0 = ~(e & ~a1 & ~a0 & x0);
    assign w1 = ~(e & ~a1 &  a0 & x1);
    assign w2 = ~(e &  a1 & ~a0 & x2);
    assign w3 = ~(e &  a1 &  a0 & x3);
    assign y  = ~(w0 & w1 & w2 & w3);
endmodule
```

**Поведенческое описание (наиболее удобное):**

```verilog
module mux_4x1_beh (
    input  wire e,
    input  wire [1:0] a,
    input  wire [3:0] x,
    output reg y
);
    always @(*) begin
        if (!e)
            y = 1'b0;
        else
            case (a)
                2'b00: y = x[0];
                2'b01: y = x[1];
                2'b10: y = x[2];
                2'b11: y = x[3];
            endcase
    end
endmodule
```

#### Использование мультиплексора для реализации булевой функции (Универсальный логический модуль)

Любую булеву функцию от `n` переменных можно реализовать на мультиплексоре с `n-1` адресным входом, подав константы 0 или 1 на информационные входы. Например, функция трёх переменных `F(A,B,C)` может быть построена на мультиплексоре 4×1, где адресные входы – `A,B`, а на информационные входы подаются выражения от `C` (0,1,`C`,`~C`).

**Задание от преподавателя:** получить таблицу истинности некоторой булевой функции и построить мультиплексорную реализацию.

### 3.4. Демультиплексоры

**Демультиплексор** направляет сигнал с единственного информационного входа на один из выходов в соответствии с адресным кодом. Он может быть построен на основе дешифратора с входом разрешения: информационный вход подключается к входу разрешения дешифратора.

**Verilog-модуль демультиплексора 1×4:**

```verilog
module demux_1x4 (
    input  wire x, a1, a0, en,
    output wire y0, y1, y2, y3
);
    // внутренний дешифратор
    wire d0, d1, d2, d3;
    decoder_2x4 dec (.a1(a1), .a0(a0), .en(1'b1), .y0(d0), .y1(d1), .y2(d2), .y3(d3));
    
    assign y0 = x & d0 & en;
    assign y1 = x & d1 & en;
    assign y2 = x & d2 & en;
    assign y3 = x & d3 & en;
endmodule
```

**Альтернативный вариант:** использовать дешифратор, где вход `en` дешифратора соединяется с информационным входом `x`.
