## 2. Краткий экскурс в Verilog для счётчиков

Счётчики являются последовательностными устройствами и строятся на триггерах (D или JK). В Verilog они описываются с использованием блоков `always @(posedge clk)` и неблокирующих присваиваний `<=`.

### 2.1. Базовый шаблон счётчика

```verilog
module counter #(parameter WIDTH = 4) (
    input wire clk,
    input wire rst,
    output reg [WIDTH-1:0] count
);
    always @(posedge clk or posedge rst) begin
        if (rst) count <= 0;
        else count <= count + 1;
    end
endmodule
```

### 2.2. Асинхронные и синхронные счётчики

- **Асинхронный (ripple counter)** – триггеры соединены последовательно, выход предыдущего является тактовым для следующего. В Verilog моделируется структурно (цепочка триггеров) или поведенчески, но структурная модель нагляднее.
- **Синхронный** – все триггеры тактируются общим сигналом `clk`. Управление переключением осуществляется через логику на входах J-K или через разрешение счёта.

## 3. Теоретическая часть

**Счётчик** – узел вычислительных устройств, предназначенный для подсчёта числа входных сигналов (импульсов). Счётчики применяются в делителях частоты, распределителях сигналов, для подсчёта шагов программы, циклов операций и т.д.

### 3.1. Классификация

| Признак | Типы |
|---------|------|
| **Система счисления** | двоичные, двоично-десятичные, десятичные, с произвольным модулем |
| **Направление счёта** | суммирующие (вперёд), вычитающие (назад), реверсивные |
| **Способ синхронизации** | асинхронные, синхронные |

### 3.2. Основные параметры

- **Модуль счёта (коэффициент пересчёта) `K_сч`** – число различных состояний счётчика. Для `n`-разрядного двоичного счётчика `K_сч = 2^n`.
- **Максимальная частота `f_сч max`** – определяется быстродействием триггеров.

### 3.3. Принцип построения асинхронных счётчиков

Асинхронный счётчик представляет собой цепочку триггеров, работающих в счётном (T) режиме. Для D-триггера счётный режим создаётся соединением инверсного выхода со входом D. Тактовый вход последующего триггера подключается либо к прямому, либо к инверсному выходу предыдущего в зависимости от направления счёта.

**Правило для D-триггеров:**
- Суммирующий: `clk_i+1 = ~Q_i` (инверсный выход)
- Вычитающий: `clk_i+1 = Q_i` (прямой выход)

**Для JK-триггеров** (в счётном режиме J=K=1):
- Суммирующий: `clk_i+1 = Q_i`
- Вычитающий: `clk_i+1 = ~Q_i`

### 3.4. Синхронные счётчики

В синхронных счётчиках все триггеры тактируются общим сигналом. Переключение конкретного разряда происходит только тогда, когда все младшие разряды находятся в состоянии «1». Это реализуется с помощью логики «И» на входах J и K (или на входе разрешения счёта). В Verilog синхронный счётчик удобно описывать поведенчески.

### 3.5. Счётчики с произвольным модулем (пересчётные схемы)

Для получения `K_сч ≠ 2^n` применяют обратную связь, которая при достижении заданного кода сбрасывает счётчик в 0. Код сброса определяется двоичным представлением `K_сч`. Элемент «И» на прямых выходах соответствующих разрядов формирует сигнал сброса.

Пример: для `K_сч = 10` (двоичный код 1010) сброс производится по выходу элемента «И» от разрядов Q3 и Q1 (при нумерации с 1).

## 4. Verilog-модели счётчиков

### 4.1. D-триггер для асинхронного счётчика (счётный режим)

```verilog
// D-триггер с инверсной обратной связью (счётный режим)
module t_ff_d (
    input wire clk,
    input wire rst,
    output reg q
);
    always @(posedge clk or posedge rst) begin
        if (rst) q <= 1'b0;
        else q <= ~q;
    end
endmodule
```

### 4.2. Асинхронный суммирующий 4-разрядный счётчик на D-триггерах

**Модуль `async_up_counter_d.v` (структурный):**

```verilog
module async_up_counter_d #(parameter WIDTH = 4) (
    input wire clk,   // входные импульсы
    input wire rst,
    output wire [WIDTH-1:0] q
);
    genvar i;
    wire [WIDTH-1:0] q_internal;
    wire [WIDTH-1:0] clk_internal;
    
    assign clk_internal[0] = clk;
    generate
        for (i = 0; i < WIDTH; i = i+1) begin : ripple
            t_ff_d ff (
                .clk(clk_internal[i]),
                .rst(rst),
                .q(q_internal[i])
            );
            if (i < WIDTH-1) assign clk_internal[i+1] = ~q_internal[i];
        end
    endgenerate
    assign q = q_internal;
endmodule
```

*Примечание:* на практике поведенческое описание асинхронного счётчика проще, но структурное ближе к реальной схеме.

### 4.3. Асинхронный суммирующий счётчик на JK-триггерах (J=K=1)

**Модуль JK-триггера в счётном режиме (T-триггер):**

```verilog
module t_ff_jk (
    input wire clk,
    input wire rst,
    output reg q
);
    always @(posedge clk or posedge rst) begin
        if (rst) q <= 1'b0;
        else q <= ~q;
    end
endmodule
```

**Асинхронный суммирующий счётчик на JK:**

```verilog
module async_up_counter_jk #(parameter WIDTH = 4) (
    input wire clk,
    input wire rst,
    output wire [WIDTH-1:0] q
);
    wire [WIDTH-1:0] clk_internal;
    wire [WIDTH-1:0] q_int;
    assign clk_internal[0] = clk;
    generate
        for (i = 0; i < WIDTH; i = i+1) begin
            t_ff_jk ff (.clk(clk_internal[i]), .rst(rst), .q(q_int[i]));
            if (i < WIDTH-1) assign clk_internal[i+1] = q_int[i]; // прямой выход
        end
    endgenerate
    assign q = q_int;
endmodule
```

### 4.4. Асинхронный реверсивный счётчик

Реверсивный счётчик имеет вход `up_down` (1 – суммирование, 0 – вычитание). В асинхронной реализации на JK-триггерах сигнал тактирования для следующего разряда выбирается мультиплексором: при суммировании – прямой выход, при вычитании – инверсный.

```verilog
module async_reversible_counter #(parameter WIDTH = 4) (
    input wire clk,
    input wire rst,
    input wire up_down,   // 1 - up, 0 - down
    output wire [WIDTH-1:0] q
);
    wire [WIDTH-1:0] clk_internal;
    wire [WIDTH-1:0] q_int;
    
    assign clk_internal[0] = clk;
    generate
        genvar i;
        for (i = 0; i < WIDTH; i = i+1) begin
            t_ff_jk ff (.clk(clk_internal[i]), .rst(rst), .q(q_int[i]));
            if (i < WIDTH-1) begin
                assign clk_internal[i+1] = up_down ? q_int[i] : ~q_int[i];
            end
        end
    endgenerate
    assign q = q_int;
endmodule
```

### 4.5. Синхронный суммирующий счётчик на JK-триггерах

В синхронном счётчике все триггеры тактируются общим `clk`, а разрешение переключения каждого разряда формируется комбинационной логикой. В Verilog поведенческое описание проще.

```verilog
module sync_up_counter #(parameter WIDTH = 4) (
    input wire clk,
    input wire rst,
    output reg [WIDTH-1:0] count
);
    always @(posedge clk or posedge rst) begin
        if (rst) count <= 0;
        else count <= count + 1;
    end
endmodule
```

Это простейший синхронный двоичный счётчик. Для JK-триггеров можно описать структурно, но поведенческий вариант абсолютно эквивалентен по функциональности и предпочтителен для моделирования.

### 4.6. Счётчик с произвольным модулем (K_сч = 5)

Счётчик до 5 (состояния 0,1,2,3,4) сбрасывается при достижении 5 (0101). Логика сброса: `rst_internal = count == 5`.

```verilog
module counter_mod5 (
    input wire clk,
    input wire rst,
    output reg [2:0] count   // 3 разряда достаточно (0..4)
);
    always @(posedge clk or posedge rst) begin
        if (rst) count <= 0;
        else if (count == 3'd5) count <= 0;
        else count <= count + 1;
    end
endmodule
```

Для проверки на временной диаграмме видно, что после 4 следующий импульс обнуляет счётчик.

### 4.7. Двоично-десятичный счётчик (K_сч = 10)

Счётчик до 9 (0…9), сброс при 10 (1010). Используется 4 разряда.

```verilog
module bcd_counter (
    input wire clk,
    input wire rst,
    output reg [3:0] count
);
    always @(posedge clk or posedge rst) begin
        if (rst) count <= 0;
        else if (count == 4'd10) count <= 0;
        else count <= count + 1;
    end
endmodule
```
