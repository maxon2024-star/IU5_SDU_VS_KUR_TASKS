### Теоретическая база: Как работает Ассемблер?

Ассемблер — это простейший компилятор. Его работа обычно делится на **Два прохода (Two-pass assembly)**:

* **Первый проход (Pass 1):** Программа читает весь текст сверху вниз, игнорирует инструкции, но ищет **Метки (Labels)** (например, `LOOP:`). Она запоминает, на какой строке (каком адресе памяти) находится каждая метка, и сохраняет это в "Таблицу символов" (Symbol Table).
* **Второй проход (Pass 2):** Программа снова читает текст, но теперь переводит инструкции (например, `ADD R1, R2`) в бинарный код. Если она встречает команду перехода (например, `JMP LOOP`), она смотрит в Таблицу символов, находит там адрес `LOOP` и вставляет его в машинный код.

### 3.1 Пример входного файла (`program.asm`)

Ваш ассемблер должен уметь "переваривать" примерно такой текст:

```nasm
// Инициализация
    LDI R1, 10      // R1 = 10 (Счетчик)
    LDI R2, 0       // R2 = 0  (Сумма)
    LDI R3, 1       // R3 = 1  (Константа декремента)

LOOP_START:         // Метка начала цикла
    ADD R2, R2, R1  // R2 = R2 + R1
    SUB R1, R1, R3  // R1 = R1 - 1
    JNZ R1, LOOP_START // Если R1 != 0, прыгаем на LOOP_START

    STORE R2, 0xFF  // Сохранить ответ в периферийный порт MMIO
    HALT            // Конец программы

```

### 3.2 Рекомендации по выбору языка

* **Python:** Рекомендуется большинству. Работа со строками (`.split()`, `.replace()`) и словарями (`dict` для меток) в Python делается элементарно. Вы напишете этот инструмент за вечер.
* **Rust / C++:** Рекомендуется тем, кто хочет пойти в системное программирование (разработка компиляторов). Использование абстрактных синтаксических деревьев (AST) и паттерн-матчинга (`match`) сделает ваш код профессиональным.
* **C (Чистый Си):** Не рекомендуется из-за ручного управления памятью при склеивании строк, но разрешается для хардкорщиков.

### 3.3 Пример шаблона на Python (Скелет архитектуры)

Ниже показан базовый пример того, как можно организовать парсинг.

```python
import sys

# Ваша архитектура (ISA Freeze)
OPCODES = {
    "ADD":   "0001",
    "SUB":   "0010",
    "LDI":   "0011",
    "STORE": "0100",
    "JNZ":   "1000",
    "HALT":  "1111"
}

def parse_register(reg_str):
    # Превращает "R1" в "0001", "R15" в "1111"
    reg_num = int(reg_str.replace("R", ""))
    return f"{reg_num:04b}"

def assemble_line(line, symbol_table):
    parts = line.replace(",", " ").split()
    instruction = parts[0]
    
    if instruction == "ADD":
        # Формат: ADD Rd, Rs1, Rs2 -> [Opcode(4)][Rd(4)][Rs1(4)][Rs2(4)]
        rd = parse_register(parts[1])
        rs1 = parse_register(parts[2])
        rs2 = parse_register(parts[3])
        return f"{OPCODES['ADD']}_{rd}_{rs1}_{rs2}"
    
    elif instruction == "JNZ":
        # Формат: JNZ Rs, Label -> [Opcode(4)][Rs(4)][Address(8)]
        rs = parse_register(parts[1])
        label = parts[2]
        if label in symbol_table:
            addr = f"{symbol_table[label]:08b}"
            return f"{OPCODES['JNZ']}_{rs}_{addr}"
        else:
            raise ValueError(f"Неизвестная метка: {label}")
    # ... логика для остальных команд ...
    
    return "0000_0000_0000_0000"

def main():
    with open("program.asm", "r") as f:
        lines = f.readlines()
        
    # --- PASS 1: Сбор меток и удаление мусора ---
    clean_code = []
    symbol_table = {}
    address_counter = 0
    
    for line in lines:
        line = line.split("//")[0].strip() # Удаляем комментарии
        if not line: continue
        
        if line.endswith(":"): # Нашли метку
            label_name = line[:-1]
            symbol_table[label_name] = address_counter
        else:
            clean_code.append(line)
            address_counter += 1 # Увеличиваем PC только для реальных инструкций
            
    # --- PASS 2: Генерация машинного кода ---
    machine_code = []
    for line in clean_code:
        bin_str = assemble_line(line, symbol_table)
        machine_code.append(bin_str)
        
    # Запись результата
    with open("firmware.bin", "w") as f:
        f.write("\n".join(machine_code))
        print("Успех! Файл firmware.bin сгенерирован.")

if __name__ == "__main__":
    main()

```

### Критерии успешной сдачи

1. **Двухпроходность:** Ассемблер успешно справляется с Forward References (прыжками вперед на метку, которая еще не объявлена).
2. **Игнорирование мусора:** Ассемблер не падает от пустых строк, лишних пробелов и табуляций.
3. **Фича варианта:** Заявленная в варианте специфика (Макросы, .data, выражения) работает корректно.
4. **Интеграция:** Сгенерированный файл успешно загружается функцией `$readmemb` / `$readmemh` в вашу память `rom.v` из Лабораторной №5, и процессор выполняет этот код.
