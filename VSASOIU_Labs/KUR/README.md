# Курсовая работа по дисциплине «Вычислительные средства АСОИУ»

**Тема:** Проектирование, верификация и реализация процессорного ядра на языке Verilog

## 1. Цель работы

Получение практических навыков современного проектирования цифровых устройств (RTL Design), освоение языка описания аппаратуры Verilog, методов автоматизированной верификации логики и синтеза для программируемых логических интегральных схем (ПЛИС/FPGA). Закрепление навыков разработки низкоуровневого программного обеспечения для кастомных вычислительных архитектур.

## 2. Основное задание

Разработать функциональную модель специализированного процессорного ядра, обладающего собственной системой команд (ISA), и реализовать его на целевой платформе (ПЛИС или детальная симуляция).

**Важное ограничение:** 

Для описания аппаратуры (RTL) используется исключительно язык Verilog. Сторонние языки (Python, C++, Bash) разрешены только для написания скриптов, ассемблеров, генераторов тестов и анализаторов.

## 3. Этапы выполнения работы

### Этап 1: Разработка архитектуры и системы команд (ISA Design)

**Задача:** Спроектировать собственную упрощенную систему команд под заданный вычислительный сценарий.

**Требования:**
*   Определить формат команды (поля opcode, регистры, immediate-значения).
*   Определить архитектуру регистрового файла (кол-во регистров, разрядность, поведение R0, тип сброса).
*   Реализовать базовый набор команд:
    *   Арифметика: ADD, SUB.
    *   Логика: AND, OR, XOR, NOT.
    *   Память: LOAD, STORE.
    *   Поток управления: JUMP, BEQ (Branch if Equal).

**Результат:** Документ «Описание архитектуры (ISA Manual)».

### Этап 2: Проектирование на языке HDL (RTL Design)

**Задача:** Описать аппаратную реализацию процессора на языке Verilog.

**Требования:**
*   Код должен быть модульным. Обязательные модули: ALU, Register_File, Control_Unit (конечный автомат), Program_Counter, Memory_Top, CPU_Core.
*   Использование синхронной логики (тактирование, сброс) для всех элементов хранения состояния.
*   Код должен быть снабжен комментариями и соответствовать стандартам стиля (coding style).

**Результат:** Исходный код проекта (файлы .v).

### Этап 3: Верификация и симуляция (Verification)

**Задача:** Доказать корректность работы устройства до этапа синтеза.

**Требования:**
*   Написать тестовое окружение (Testbench).
*   Тестбенч должен автоматически подавать сигналы тактирования и сброса.
*   Реализовать сценарий проверки: загрузка тестовой программы в память -> запуск процессора -> проверка результатов в регистрах/памяти.
*   Предоставить временные диаграммы (waveforms), подтверждающие прохождение тестов.

**Результат:** Файл тестбенча, лог симуляции, скриншоты временных диаграмм.

### Этап 4: Синтез и реализация (Synthesis & Implementation)

**Задача:** Оценить физические параметры проекта.

**Требования:**
*   Выполнить синтез проекта в среде разработки для ПЛИС (Xilinx Vivado, Intel Quartus или Yosys).
*   Проанализировать отчет об использовании ресурсов (LUT, Flip-Flops, Block RAM).
*   Определить максимальную рабочую частоту (Fmax).

**Результат:** Отчеты синтеза, сведения о занимаемых ресурсах и быстродействии.

### Этап 5: Программно-аппаратная интеграция (Advanced)

**Задача:** Написать программу для созданного процессора, решающую вычислительную задачу по индивидуальному варианту.

**Часть 1**
*   Составить минимальный машинный код для решения задачи варианта.
*   Продемонстрировать корректное выполнение программы на спроектированном процессоре.

**Часть 2:**
*   Разработать собственный ассемблер (скрипт на Python/C++), который парсит текстовый файл, а на выходе генерирует бинарный/шестнадцатеричный файл прошивки, совместимый с `$readmemb`/`$readmemh`.
*   Написать на разработанном ассемблере программу решения задачи варианта.
*   Сравнить скомпилированный машинный код с составленным в части 1.
*   Продемонстрировать корректное выполнение скомпилированной программы на спроектированном процессоре.

**Важно:**
*   **На оценку 3** достаточно выполнить только первую часть.
*   **На оценку 4-5** необходимо выполнить обе части.

**Результат:** Машинный код, доказательство корректного выполнения программы, исходный код ассемблера и программы и скомпилированный машинный код с доказательством корректного выполнения (если выполнена часть 2).

## 4. Требования к отчету

Отчет должен содержать:

1.  Титульный лист.
2.  Описание разработанной системы команд (ISA).
3.  Схема архитектуры процессора (блок-схема взаимосвязи модулей).
4.  Листинги ключевых модулей на Verilog (с комментариями).
5.  Описание методики тестирования и примеры тестовых векторов.
6.  Временные диаграммы работы ключевых узлов.
7.  Отчет о синтезе (занимаемые ресурсы, частота).
8.  Описание формата входных/выходных данных, машинный код, исходный код ассемблера и скомпилированный машинный код (если выполнена часть 2 этапа 5).
9.  Выводы о проделанной работе и возможных путях оптимизации.

## 5. Инструментарий

*   **Языки:** Verilog – для RTL-кода, Python 3.x / C++ - для написания ассемблера, генераторов тестов.
*   **САПР:** Xilinx Vivado (WebPACK), Intel Quartus (Prime Lite), или открытые инструменты (Icarus Verilog + GTKWave, Yosys).
*   **Контроль версий:** Git (обязательно, наличие репозитория с историей коммитов).
